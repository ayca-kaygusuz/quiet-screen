# Quiet Screen for Android

Android 8+ packages the shared interface, records, episodes, movie resume points,
lists, themes and Drive sync model. Google uses native Play services and the
registered package/certificate; user tokens stay native. No PC/server is needed.

Use Java 21, SDK 36 and npm run build:android, or the Android workflow. Production
publication requires the original signing key. Lint and emulator instrumentation
must pass before attaching an immutable signed APK to the exact-source release.

The bridge is origin-bound and main-frame only, with fixed operations and bounded
native HTTP. Backups use system document pickers. Exports exclude tokens and keys.
See ../PLATFORMS.md for setup. Real-device Google consent and file-picker checks
are distinct from emulator tests. Preserve the upstream compatibility source and
license notices provided with the APK.
